# GlassDock

Dock per Windows di **corrymanfra**.

[Scarica GlassDock per Windows x64](https://github.com/corrymanfra/GlassDock-updates/releases/download/v1.2/GlassDock-Setup-1.2-x64.exe)

Dalla versione 1.2 gli aggiornamenti arrivano direttamente dal dock: quando disponibili compare **Aggiorna ora**. Durante il download il dock mostra una timeline; dopo la breve riapertura compare dal centro verso i lati.

Chi usa ancora la versione 1.1 deve installare una volta la versione 1.2, conservando le preferenze. Per controllare manualmente: Impostazioni → Sistema → Controlla aggiornamenti.

Questa repository contiene soltanto l’app compilata, installer e pacchetti firmati. I sorgenti sono conservati in una repository privata. Gli archivi automatici «Source code» di GitHub relativi a questa repository non contengono il progetto dell’app.

Sviluppato da corrymanfra.
